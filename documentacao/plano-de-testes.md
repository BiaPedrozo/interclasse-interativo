# Plano de testes — Interclasse Interativo

## 1. Objetivo e ambiente

Este plano descreve verificações para as funções atuais e para a versão alvo. Salvo o CT18, os casos estão **não executados**: o campo de resultado indica apenas o que se espera observar. Os casos que exigem backend estão pendentes até que ele seja implementado. Executar os casos de interface em navegador atualizado, primeiro por servidor HTTP local estático para permitir avaliação do IndexedDB, e anotar navegador, versão, largura de tela, data e evidências.

## 3. Registro de execução

Para transformar este plano em relatório de testes, preencher por caso executado: data, responsável, navegador/versão, largura de tela, resultado real (aprovado/reprovado), evidência e defeito relacionado. O CT18 foi executado em SQLite em memória por `winsqlite3.dll` do Windows; os testes restantes não foram executados. A migração verificada ainda não é usada por um servidor. Não registrar “aprovado” somente com base no resultado esperado descrito acima.
