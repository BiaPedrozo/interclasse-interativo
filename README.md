# Interclasse Interativo

Site demonstrativo responsivo para um campeonato escolar, feito com HTML, CSS e JavaScript puro. Os nomes, datas, jogos, placares, votações e números exibidos são fictícios e servem somente para ilustrar a interface.

## Arquivos

- `index.html`: estrutura das seções, conteúdo e navegação do site.
- `css/styles.css`: identidade visual azul-escuro, branco e laranja, incluindo os ajustes para telas menores.
- `js/app.js`: menu móvel, confirmação demonstrativa de voto e aviso da área administrativa.
- `assets/images/`: pasta reservada para fotos e ilustrações que venham a ser adicionadas.

## Como executar

Abra `index.html` em um navegador moderno. Também é possível abrir a pasta no editor e usar a extensão de servidor local de sua preferência, sem instalar dependências para este projeto.

O site não envia votos nem salva dados. As imagens da galeria e a arte principal são formas CSS e elementos visuais demonstrativos. A fonte DM Sans e Space Grotesk é carregada do Google Fonts quando há conexão com a internet; caso contrário, o navegador usa fontes alternativas.
